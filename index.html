Web Development • Full-Stack Completed

Smart Attendance System

A comprehensive web-based application developed to help educational institutions modernize and digitize student records and attendance logging. Provides seamless multi-user role authentication and integrates QR code scanning technology for library access.

Problem Being Solved

Eliminates the inefficiencies, paper waste, and human calculation errors associated with manual pen-and-paper attendance registers. By offering real-time digital recording for class sessions and instantaneous QR code validation for library entry, it dramatically accelerates administrative tracking and makes attendance data reliable and transparent.

Key Contributions & Engineering Scope
Frontend UI Design: Crafted clean, responsive user interfaces using HTML5, CSS3, and JavaScript for seamless interaction across desktop and tablet screens.
Backend & Database Architecture: Programmed server-side request processing in PHP connected to a normalized MySQL relational database schema.
Role-Based Modules: Implemented dedicated portal workflows for Admin (institutional oversight), Faculty (marking class attendance), and Students (personal attendance metrics).
Library QR Code Integration: Integrated QR code scanning mechanism for fast, contactless library attendance tracking.
