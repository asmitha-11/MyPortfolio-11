# Asmitha - Developer Portfolio Website

A minimal, professional, and accessible personal developer portfolio built for **Asmitha**, First-Year Master of Computer Applications (MCA) student at Poornaprajna Institute of Management (PIM), Udupi, Karnataka.

![Portfolio Preview](assets/profile.jpg)

---

## 🌟 Key Highlights

- **Aesthetic:** Minimal and Professional Black & White / Monochromatic design system with Slate/Stone accents.
- **Theme Toggle:** Default Light Theme with a persistent Dark / Light mode toggle (`localStorage`).
- **Mobile-First & Responsive:** Smooth navigation and layout across mobile phones, tablets, laptops, and widescreen monitors.
- **Accessibility:** Semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), ARIA attributes, and WCAG 2.1 AA compliant color contrast.
- **Authentic Student Profile:** Exact, verified self-assessed proficiency levels (`Basic`) across C, C++, Python, Java, PHP, R, JavaScript, HTML, CSS, and SQL.
- **Featured Project:**
  - **Smart Attendance System:** Web-based institutional attendance system developed in PHP, MySQL, HTML, CSS, and JavaScript with multi-role access (Admin, Faculty, Students) and automated QR code library scanning.
- **Interactive Resume:** In-modal resume viewer, printable formatting with `window.print()`, and a standalone resume page.
- **Direct Contact:** 1-click clipboard copy for email and phone, plus responsive contact form.

## 🚀 How to Run Locally

### Option 1: Open Directly in Browser
Simply double-click `index.html` or open it with any modern web browser.

### Option 2: Using Node.js (Built-in Server)
Run the zero-dependency local static server:
```bash
npm start
# or
node server.js
```
Then navigate to [http://localhost:8080/](http://localhost:8080/) in your browser.
